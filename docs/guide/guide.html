Ce que contient ce guide

01

Comprendre

Ce qu'est Claude, ce qu'est un skill, et ce que reverse-motion fait pour vous. Sans ces bases, le reste paraîtra obscur : prenez dix minutes.

Chapitre 1

Claude, Claude Code et les skills

Trois mots reviennent dans tout le guide. Les voici expliqués simplement.

L'ASSISTANT

Claude

Une intelligence artificielle créée par Anthropic. On lui écrit en français, comme à une personne, et il répond ou il agit. On l'utilise dans l'application Claude (site claude.ai, ordinateur, téléphone).

L'OUTIL DE TRAVAIL

Claude Code

Le même Claude, mais qui travaille directement sur votre ordinateur : il ouvre des fichiers, lance des programmes, fabrique des vidéos. On le démarre depuis une fenêtre appelée terminal (chapitre 4).

Et un « skill », c'est quoi ?

Un skill (« compétence » en anglais) est un dossier qu'on donne à Claude. Il contient :

  • un mode d'emploi écrit pour Claude (le fichier SKILL.md) : la méthode, les étapes, les règles ;
  • des outils (petits programmes) que Claude utilise en suivant ce mode d'emploi.
Une image pour retenir

Claude est un excellent cuisinier. Un skill, c'est le cahier de recettes et les ustensiles d'un chef spécialisé. Sans le cahier, Claude cuisine bien, mais à sa façon. Avec le cahier, il reproduit la recette exacte, avec les bons outils, et vérifie le résultat comme le chef le ferait.

Une fois le skill installé, vous n'avez rien de technique à faire : vous parlez à Claude normalement, et il ouvre le skill tout seul quand votre demande le concerne. Vous pouvez aussi l'appeler par son nom en tapant /reverse-motion.

Ce qu'il vous faut

ÉlémentDétail
Un ordinateurWindows 10/11 ou macOS récent. 8 Go de mémoire minimum (16 Go conseillés), 5 Go d'espace libre (les outils et Blender pèsent lourd).
Un abonnement Claude payantClaude Code demande un abonnement Pro, Max, Team ou Enterprise (l'offre gratuite ne suffit pas). Pour des vidéos longues ou nombreuses, Max évite d'atteindre la limite d'utilisation en plein travail. Les offres changent : vérifiez-les sur claude.com/pricing.
Une connexion internetStable, surtout pendant l'installation (plusieurs centaines de Mo à télécharger).
Du tempsInstallation : 45 à 90 min, une seule fois. Reproduction d'une vidéo de 30 à 60 s : plusieurs heures de travail de Claude (vous n'avez pas besoin de rester devant).
Chapitre 2

Ce que fait reverse-motion

Vous donnez une vidéo de motion design (une pub animée, une intro, une vidéo de textes animés). Claude la recrée entièrement en code, image par image, puis la mesure pour prouver qu'elle est identique.

Pourquoi tout recréer ?

Parce que l'intérêt n'est pas d'avoir une copie : c'est de pouvoir changer ce que vous voulez ensuite. Une vidéo recréée en code se modifie en une phrase : autres textes, autres couleurs, votre logo, une autre durée, votre voix. C'est la règle n° 1 du skill : tout est recréé (fonds, formes, textes, icônes, objets 3D, effets). Seules les images de personnes réelles ou d'objets réels filmés sont reprises telles quelles dans l'original.

Les icônes et objets en relief (3D) sont remodelés automatiquement avec Blender, un logiciel de 3D gratuit que l'installation ajoute pour vous.

Ce que le skill ne fait pas

Il ne fait pas…Ce que vous faites à la place
Générer une voix offVous la créez avec ElevenLabs ou vous l'enregistrez (chapitre 12). Claude l'intègre ensuite.
Chercher une musique de fondVous la choisissez dans la Bibliothèque audio de YouTube (chapitre 13). Claude la mixe sous la voix.
Écrire votre script à votre placeVous rédigez le texte (chapitre 11). Claude peut vous aider à l'améliorer si vous le lui demandez.
Donner des droits sur la vidéo d'un autreVoir l'encadré ci-dessous.
Droits d'auteur

La copie exacte de la vidéo de quelqu'un d'autre sert à apprendre et à s'entraîner : ne la publiez pas telle quelle. Pour un usage commercial, publiez la version adaptée à votre marque (vos textes, vos couleurs, votre voix, votre musique). Le skill vous le rappellera.

Chapitre 3

Ouvrir et utiliser le terminal

Le terminal est une fenêtre où l'on écrit des commandes au lieu de cliquer. Il fait peur au début, mais vous n'aurez qu'à copier-coller les commandes de ce guide.

WINDOWS

Ouvrir PowerShell

  1. Appuyez sur la touche Windows du clavier.
  2. Tapez PowerShell.
  3. Cliquez sur Windows PowerShell (ou Terminal).

Une fenêtre s'ouvre avec une ligne qui finit par >, par exemple PS C:\Users\Awa>.

MAC

Ouvrir le Terminal

  1. Appuyez sur Cmd + Espace.
  2. Tapez Terminal.
  3. Appuyez sur Entrée.

Une fenêtre s'ouvre avec une ligne qui finit par % ou $, par exemple awa@MacBook ~ %.

Les 5 gestes à connaître

GesteComment
Coller une commandeWindows : clic droit dans la fenêtre ou Ctrl + V. Mac : Cmd + V.
Lancer la commandeAppuyez sur Entrée. Attendez que la ligne > ou % réapparaisse avant d'en lancer une autre.
Arrêter quelque choseCtrl + C (Windows et Mac).
Rappeler la commande précédenteFlèche ↑ du clavier.
Rouvrir le terminalFermez la fenêtre et rouvrez-la comme ci-dessus. C'est nécessaire après chaque installation d'outil, pour que le terminal le « voie ».

Lire ce que le terminal répond

Exemple
> node --version
v22.11.0                       ← un numéro : l'outil est installé

> ffmpeg -version
ffmpeg : Le terme « ffmpeg » n'est pas reconnu…   ← l'outil manque ou le terminal n'a pas été rouvert
Astuce

Un message en anglais n'est pas forcément une erreur. Le mot à surveiller est error ou erreur. En cas de doute, copiez le message et collez-le à Claude (dans l'application) en demandant « que veut dire ce message ? ».

Attention

Ne copiez pas le symbole > ou % du début des exemples : il est déjà affiché par le terminal. Copiez seulement la commande.

Chapitre 4

Installer les outils de base

Le skill a besoin de cinq outils gratuits. Vous n'aurez jamais à les ouvrir vous-même : Claude s'en sert.

OutilÀ quoi il sert
GitTélécharger le skill depuis GitHub et le mettre à jour.
Node.jsFaire tourner le moteur qui dessine la vidéo image par image.
PythonFaire tourner les outils de mesure et Blender.
ffmpegLire et fabriquer les fichiers vidéo et audio.
TesseractLire les textes qui apparaissent dans la vidéo.

Sur Windows

Windows 10/11 contient un installateur appelé winget. Dans PowerShell, copiez ces lignes une par une (Entrée après chacune, attendez la fin, acceptez si Windows demande une autorisation) :

PowerShell — Windows
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.13 -e
winget install --id Gyan.FFmpeg -e
winget install --id UB-Mannheim.TesseractOCR -e

Tesseract ne s'ajoute pas tout seul à la liste des programmes connus du terminal. Collez cette commande (une seule ligne) :

PowerShell — Windows
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\Program Files\Tesseract-OCR", "User")

Fermez PowerShell et rouvrez-le, puis passez à la vérification ci-dessous.

Si « winget » n'est pas reconnu

Ouvrez le Microsoft Store, cherchez App Installer (Programme d'installation d'application) et mettez-le à jour, puis rouvrez PowerShell.

Sur Mac

On utilise Homebrew, l'installateur de référence sur Mac. Collez cette commande dans le Terminal (une seule ligne). Elle demande votre mot de passe de session : tapez-le, il ne s'affiche pas, c'est normal, puis Entrée.

Terminal — Mac
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

À la fin, Homebrew affiche une rubrique Next steps avec deux ou trois commandes : copiez-les et lancez-les aussi. Puis installez les outils :

Terminal — Mac
brew install git node python@3.13 ffmpeg tesseract tesseract-lang

Fermez le Terminal et rouvrez-le.

Vérifier

Windows et Mac
git --version
node --version
python --version        # sur Mac : python3 --version
ffmpeg -version
tesseract --version
Vérifiez

Chaque commande affiche un numéro de version (Node 18 ou plus, Python 3.9 ou plus, 3.13 conseillé). Si l'une dit « n'est pas reconnu » ou « command not found » : rouvrez le terminal ; si ça persiste, réinstallez cet outil.

Chapitre 5

Installer Claude Code et se connecter

Claude Code est l'outil qui fera tout le travail. Son installation tient en une commande.

Installer

PowerShell — Windows
irm https://claude.ai/install.ps1 | iex
Terminal — Mac
curl -fsSL https://claude.ai/install.sh | bash

Fermez et rouvrez le terminal, puis vérifiez :

Windows et Mac
> claude --version
2.x.x (Claude Code)

Se connecter (une seule fois)

  1. Dans le terminal, tapez claude puis Entrée.
  2. Claude Code pose quelques questions de départ (thème de couleurs, etc.) : choisissez avec les flèches et validez avec Entrée.
  3. Choisissez la connexion avec votre compte Claude (abonnement). Votre navigateur s'ouvre : connectez-vous et autorisez.
  4. De retour dans le terminal, Claude Code affiche une zone où écrire. Vous êtes connecté.
  5. Pour quitter Claude Code : tapez /exit ou appuyez deux fois sur Ctrl + C.
Astuce

Claude Code existe aussi dans l'application de bureau Claude et dans des éditeurs comme VS Code. Ce guide utilise le terminal, qui marche partout de la même façon.

Raccourci pour la suite

À partir d'ici, Claude Code peut faire les installations à votre place. Au chapitre 6, vous avez le choix : taper les commandes vous-même (chemin A ou B), ou demander à Claude Code de s'en charger (chemin express).

Chapitre 6

Récupérer le skill

Le skill est publié sur GitHub, un site qui héberge du code. On le copie dans le dossier où Claude Code range ses skills : .claude/skills, dans votre dossier personnel.

Votre dossier personnel (C:\Users\Awa ou /Users/awa) └── .claude ← dossier de Claude Code (caché) └── skills ← vos skills └── reverse-motion ← le skill, à ce nom exact ├── SKILL.md ← mode d'emploi pour Claude ├── METHODS.md ← méthodes détaillées ├── install.sh / install.ps1 ├── engine/ ← moteur de rendu └── scripts/ ← outils de mesure, Blender…
Le dossier doit s'appeler exactement reverse-motion, sinon Claude ne le reconnaît pas.

Chemin A — avec Git (conseillé : mises à jour en une commande)

PowerShell — Windows
git clone https://github.com/oriaagentpro-a11y/reverse-motion.git "$HOME\.claude\skills\reverse-motion"
Terminal — Mac
git clone https://github.com/oriaagentpro-a11y/reverse-motion.git ~/.claude/skills/reverse-motion
Vérifiez

La dernière ligne affichée contient done (ou « Résolution des deltas : 100 % »). Aucune ligne ne commence par fatal:.

Chemin B — sans Git (téléchargement ZIP)

  1. Ouvrez github.com/oriaagentpro-a11y/reverse-motion dans votre navigateur.
  2. Cliquez sur le bouton vert Code, puis Download ZIP.
  3. Décompressez le fichier (double-clic sur Mac ; clic droit > Extraire tout sur Windows).
  4. Le dossier obtenu s'appelle reverse-motion-main : renommez-le en reverse-motion.
  5. Déplacez-le dans .claude\skills de votre dossier personnel (créez les dossiers .claude et skills s'ils n'existent pas).
Voir les dossiers cachés

Le dossier .claude est caché. Mac : dans le Finder, Cmd + Maj + . (point). Windows : Explorateur > Affichage > Afficher > cochez Éléments masqués.

Chemin express — Claude Code le fait pour vous

Lancez claude dans le terminal, puis écrivez :

À écrire à Claude Code

Installe le skill reverse-motion pour moi : clone https://github.com/oriaagentpro-a11y/reverse-motion.git dans mon dossier de skills personnels (.claude/skills/reverse-motion), puis lance son script d'installation (install.sh sur Mac, install.ps1 sur Windows) et vérifie avec scripts/doctor.py. Explique-moi chaque étape simplement et dis-moi si un outil manque.

Claude Code vous demandera d'autoriser chaque commande (voir chapitre 14). Si c'est fini et que doctor.py affiche « Tout est prêt », passez directement au chapitre 9.

Si le dépôt est introuvable (erreur 404)

Le dépôt n'est peut-être pas encore public, ou l'adresse a changé. Demandez le lien à jour (ou le fichier reverse-motion.zip) à la personne qui vous a envoyé ce guide.

Chapitre 7

Le skill a besoin de ses propres outils (moteur de rendu, outils de mesure, navigateur Chromium, Blender). Un script installe tout d'un coup.

Lancer l'installation du skill

Ce n'est pas bloquant : les objets 3D seront rendus avec Three.js (un peu moins réalistes). Pour l'ajouter plus tard : installez Blender depuis blender.org, puis relancez l'installation. Sur Mac : brew install --cask blender.

Chapitre 8

Variante : l'application Claude

Vous pouvez aussi ajouter le skill à l'application Claude (claude.ai, application de bureau). Claude y travaille dans un ordinateur virtuel en ligne : rien à installer chez vous.

À savoir avant de choisir
  • Les vidéos longues, Blender et les rendus image par image demandent beaucoup de calcul : dans l'application, le travail peut être plus lent ou s'arrêter en route. Claude Code sur votre ordinateur reste le chemin conseillé.
  • L'application convient bien pour découvrir le skill, faire analyser une vidéo, ou travailler sur une vidéo courte.

Activer l'exécution de code

  1. Dans l'application Claude, ouvrez Paramètres (Settings) > Capacités (Capabilities).
  2. Activez Créer et modifier des fichiers (appelé aussi Code execution and file creation).

Ajouter le skill

  1. Récupérez le fichier reverse-motion.zip fourni avec ce guide. Ne le décompressez pas.
  2. Dans l'application, ouvrez Customize (Personnaliser) > Skills.
  3. Cliquez sur +, puis + Create skill, puis Upload a skill.
  4. Choisissez reverse-motion.zip.
  5. Le skill apparaît dans la liste : vérifiez que son interrupteur est activé.
Vérifiez

Dans une nouvelle conversation, écrivez : « Quels skills as-tu ? Décris reverse-motion en deux phrases. » Claude doit le décrire.

Le ZIP téléchargé depuis GitHub ne passe pas ?

Le ZIP de GitHub contient un dossier nommé reverse-motion-main : l'application le refuse, car le nom du dossier doit être celui du skill. Décompressez-le, renommez le dossier en reverse-motion, recompressez-le, ou utilisez le reverse-motion.zip fourni.

Comptes Team et Enterprise

Si l'option n'apparaît pas, l'administrateur de votre organisation doit autoriser les skills et l'exécution de code.

03

Préparer vos éléments

Avant de parler à Claude, rassemblez tout dans un dossier : la vidéo modèle, votre script, votre voix off, votre musique et votre marque. Un dossier bien rangé, c'est un travail sans allers-retours.

Chapitre 9

Créer le dossier du projet

Un dossier par vidéo. Claude y lira vos fichiers et y rangera ses résultats.

Documents/videos/ma-pub-1 ← un dossier par projet, nom sans espace ni accent ├── modele.mp4 ← la vidéo à reproduire (chapitre 10) ├── script.txt ← votre texte, scène par scène (chapitre 11) ├── voix.mp3 ← votre voix off (chapitre 12) ├── musique.mp3 ← votre musique de fond (chapitre 13) └── marque/ ← facultatif ├── logo.png ← logo sur fond transparent └── couleurs.txt ← vos couleurs, ex. #E63946, #1D3557
Noms de fichiers

Pas d'espaces, pas d'accents, pas de caractères spéciaux : ma-pub-1, voix.mp3. Les noms comme Ma Pub (finale) é.mp4 provoquent des erreurs.

Seule la vidéo modèle est obligatoire. Pour une simple reproduction (sans adaptation), elle suffit.

Écrire votre marque en clair

Dans couleurs.txt, une couleur par ligne avec son rôle :

fond principal : #0B1F3A couleur d'accent : #F4A300 texte : #FFFFFF police souhaitée : Poppins (ou « la même que l'original »)
Astuce

Vous ne connaissez pas le code de vos couleurs ? Donnez votre logo à Claude et demandez : « relève les couleurs exactes de ce logo ».

Chapitre 10

Choisir la vidéo modèle

Plus la vidéo modèle est nette, plus la copie sera fidèle.

CritèreRecommandation
FormatMP4 de préférence (MOV et WebM fonctionnent aussi).
QualitéLa meilleure disponible : 1080p si possible, 720p minimum. Évitez les vidéos recompressées plusieurs fois (captures d'écran de réseaux sociaux floues).
DuréeCommencez par une vidéo de 15 à 30 secondes. Une vidéo d'une minute représente plusieurs heures de travail.
ContenuIdéal : textes animés, formes, icônes, objets 3D, transitions. Les passages avec des personnes filmées sont repris tels quels (règle n° 1).
Sans incrustationÉvitez les vidéos avec un logo de réseau social, des sous-titres ajoutés ou un filigrane par-dessus : ils seraient recréés eux aussi.
Droits

Utilisez une vidéo que vous avez le droit d'étudier. La reproduction exacte d'une vidéo d'un tiers ne se publie pas : publiez votre version adaptée (chapitre 16).

Chapitre 11

Écrire votre script

Le script dit à Claude quoi remplacer : les textes à l'écran de chaque scène et ce que dit la voix off. Gardez la même structure que la vidéo modèle, c'est ce qui permet de garder son rythme.

Étape 1 : faire l'inventaire des scènes du modèle

Demandez-le à Claude, il le fait mieux et plus vite que vous :

À écrire à Claude

Regarde modele.mp4 et fais-moi un tableau des scènes : numéro, début et fin (en secondes), textes affichés à l'écran, durée de chaque texte. Je vais m'en servir pour écrire mon script.

Étape 2 : écrire votre version, scène par scène

Modèle à copier dans script.txt :

PROJET : Pub lancement formation « Vendre en ligne » DURÉE VISÉE : identique au modèle (ou : 30 s) TON : dynamique, chaleureux SCÈNE 1 (0 – 3 s) Texte à l'écran : Tu veux vendre en ligne ? Voix off : Tu veux enfin vendre en ligne, sans te perdre ? SCÈNE 2 (3 – 7 s) Texte à l'écran : Sans site compliqué Voix off : Pas besoin d'un site compliqué ni d'un gros budget. … (une entrée par scène) SCÈNE FINALE Texte à l'écran : Inscris-toi · lien en bio Logo : marque/logo.png

Les règles d'or

  • Longueur des textes à l'écran : restez proche du nombre de mots du modèle. Un texte deux fois plus long ne tiendra pas dans la même animation.
  • Voix off : comptez environ 2,5 mots par seconde en français. Une scène de 4 s accepte une phrase d'environ 10 mots.
  • Lisez votre voix off à voix haute, chronomètre en main, avant de la générer.
  • Écrivez les nombres comme ils doivent être affichés à l'écran (« 7 jours ») et comme ils doivent être dits dans la voix off (« sept jours »).
  • Faites relire par Claude : « Vérifie que chaque texte tient dans la durée de sa scène et que la voix off se lit dans le temps prévu ; propose plus court si besoin. »
Chapitre 12

Créer la voix off

Deux options : une voix de synthèse très naturelle avec ElevenLabs, ou votre propre voix. Le résultat attendu est le même : un fichier voix.mp3 dans le dossier du projet.

Option A : ElevenLabs (voix de synthèse)

  1. Allez sur elevenlabs.io et créez un compte (bouton Sign up).
  2. Dans le menu de gauche, ouvrez Text to Speech (Synthèse vocale).
  3. Choisissez une voix (bouton de choix de voix) : écoutez-en plusieurs ; filtrez sur la langue French pour un accent français naturel.
  4. Choisissez un modèle multilingue (par exemple Eleven Multilingual v2) : c'est celui qui prononce le mieux le français.
  5. Collez uniquement le texte de la voix off de votre script, dans l'ordre des scènes. Laissez une ligne vide entre les scènes pour une petite pause.
  6. Cliquez sur Generate, écoutez, ajustez si besoin (stabilité, vitesse), régénérez.
  7. Téléchargez le résultat en MP3, renommez-le voix.mp3 et placez-le dans le dossier du projet.
Licence : à lire avant de publier
  • L'offre gratuite donne environ 10 minutes de voix par mois, mais n'autorise pas l'usage commercial et demande de créditer ElevenLabs (mentionner « elevenlabs.io » dans le titre de la vidéo).
  • Pour une pub ou une vidéo qui vend : il faut au minimum l'offre payante Starter (environ 6 $ par mois en novembre 2026), qui inclut la licence commerciale.
  • Les offres changent : vérifiez sur elevenlabs.io/pricing.
Astuce : une prononciation bizarre ?

Écrivez le mot comme il se prononce dans le texte de la voix (« I-ROKO », « 7 » → « sept »), sans toucher au texte à l'écran du script.

Option B : votre propre voix

  1. Pièce : choisissez la plus calme, avec des rideaux, des coussins ou des vêtements (ils absorbent l'écho). Coupez ventilateur et climatisation.
  2. Matériel : un téléphone récent suffit. Application Dictaphone (iPhone) ou Enregistreur (Android). Un micro-cravate améliore nettement le son.
  3. Placement : téléphone à 15-20 cm de la bouche, un peu de côté (pas en face, pour éviter les souffles sur les « p » et les « b »).
  4. Enregistrement : lisez le texte scène par scène, en laissant 1 seconde de silence entre les scènes. Recommencez une phrase ratée en entier.
  5. Nettoyage (facultatif) : avec Audacity (gratuit, audacityteam.org), réduisez le bruit de fond (menu Effet > réduction du bruit) et normalisez le volume, puis exportez en MP3.
  6. Envoyez le fichier sur votre ordinateur, renommez-le voix.mp3, placez-le dans le dossier du projet.
Astuce

Vous pouvez aussi demander à Claude de nettoyer votre enregistrement : « Nettoie voix-brute.m4a : enlève le bruit de fond, les longs silences, normalise le volume, et exporte voix.mp3 ».

Chapitre 13

Trouver la musique de fond

La source conseillée est la Bibliothèque audio de YouTube : gratuite, téléchargeable, et chaque morceau indique s'il faut créditer l'artiste.

Ne téléchargez pas une musique au hasard sur YouTube

Une chanson trouvée sur YouTube appartient à quelqu'un. Utilisée dans votre vidéo, elle peut provoquer un blocage, un retrait de la vidéo ou une réclamation de droits. Restez dans la Bibliothèque audio.

Télécharger une musique

  1. Connectez-vous à studio.youtube.com avec un compte Google (il faut une chaîne YouTube, même vide ; YouTube propose de la créer).
  2. Dans le menu de gauche, cliquez sur Bibliothèque audio (accès direct : youtube.com/audiolibrary).
  3. Utilisez la barre de filtres : Genre, Ambiance (« Joyeux », « Inspirant », « Dramatique »…), Durée.
  4. Ajoutez le filtre Attribution non requise : vous n'aurez rien à mentionner.
  5. Cliquez sur Lecture pour écouter. Choisissez un morceau au moins aussi long que votre vidéo.
  6. Survolez la date du morceau et cliquez sur Télécharger : vous obtenez un MP3.
  7. Renommez-le musique.mp3 et placez-le dans le dossier du projet.
Si le morceau demande une attribution

Son type de licence affiche une icône Creative Commons. Cliquez dessus, puis Copier : collez ce texte dans la description de votre vidéo.

Publication hors de YouTube

La Bibliothèque audio est conçue pour les vidéos YouTube, et YouTube ne précise pas l'usage sur d'autres plateformes. Pour Facebook, Instagram ou TikTok, lisez la licence du morceau, ou utilisez la musique proposée par la plateforme elle-même au moment de publier.

Choisir la bonne musique

  • Le tempo compte : une musique au rythme proche de celle du modèle garde les animations « sur le temps ». Claude mesure le tempo et peut caler les animations sur votre musique.
  • Sous une voix : préférez une musique sans chant ou avec peu de paroles.
  • Vous pouvez garder la musique du modèle uniquement si vous en avez les droits.

Le déroulé, ensuite

  1. Analyse : scènes, couleurs exactes, police, tempo de la musique, inventaire des objets 3D.
